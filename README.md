# Embedded Hardware Project

## Overview

This project presents the design and implementation of a custom microcontroller-based embedded system. The hardware was designed from the electronic schematic to the PCB layout using KiCad.

## Features

- Custom PCB design
- LCD display interface
- Temperature sensor
- Buzzer alarm
- Microcontroller-based control

## Hardware Components

- Microcontroller
- LCD display
- Temperature sensor
- Buzzer
- Custom PCB

## Development Tools

- KiCad
- Embedded C
- Git

## Repository Contents

This repository includes:
- Electronic schematic
- PCB layout
- 3D PCB model
- Firmware source code
- Project documentation

## Learning Outcomes

During this project I gained practical experience in:
- Electronic schematic design
- PCB layout design
- Embedded systems development
- Hardware debugging
- Version control using Git and GitHub
